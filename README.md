# CSI Tarkov releases

Installers for the **CSI Tarkov** desktop app for Windows: it records your own Escape from Tarkov
raids through OBS (your fights, your death, your kill list) so you can review them, and share a
case on [csi-tarkov.tflolo.com](https://csi-tarkov.tflolo.com) for others to review. It never
touches the game process: only OBS, Windows text recognition, Tarkov's log files and the screen.

**Download the latest version on the [Download page](https://csi-tarkov.tflolo.com/download)**,
or from [Releases](https://github.com/tflolo/csi-tarkov-releases/releases/latest).

- Each release lists what changed and the installer's **SHA-256**, to check the file is the one
  published here.
- The installer isn't code-signed (a free fan project). Chrome may call the file uncommon: choose
  **Keep**. Windows SmartScreen may say "Windows protected your PC": click **More info → Run
  anyway**.
- Releases are built and published automatically from the app's source on GitHub Actions. This
  repository holds only the installers; it has no source code.

CSI Tarkov is an independent fan project, not affiliated with Battlestate Games.
